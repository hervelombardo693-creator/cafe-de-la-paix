# Café de la Paix — site vitrine

Site du Café de la Paix, restaurant ouvrier à Bellerive-sur-Allier.
Ouvert le midi du lundi au samedi, et le vendredi soir pour les soirées spéciales.

## Contenu

- `site/index.html` — la page
- `site/style.css` — la mise en forme
- `site/script.js` — remplit la page à partir des données
- `site/donnees.js` — **le fichier à modifier** : menu de la semaine, soirée du vendredi, téléphone, adresse, horaires
- `site/images/` — les photos

## Voir le site en local

Ouvrir `site/index.html` dans un navigateur, ou lancer :

```
python -m http.server 8731 --directory site
```

puis aller sur http://localhost:8731
